ÁREA DE ADMINISTRAÇÃO ERALIS

Acesse:
http://localhost:8000/admin.html

Nesta primeira versão:
- produtos podem ser adicionados, editados, ativados/desativados e excluídos;
- produtos aceitam imagem, preço, descrição e link Mercado Pago;
- imagens de "Criamos ideias" podem ser adicionadas, ordenadas e excluídas;
- dados ficam salvos no localStorage do navegador;
- há exportação dos dados para JSON.

IMPORTANTE:
Esta é uma primeira etapa sem backend. As imagens são armazenadas no navegador.
Isso significa que os dados não são compartilhados entre computadores/navegadores.

Para uma versão de produção, o próximo passo é conectar o painel a:
- autenticação de administrador;
- banco de dados;
- armazenamento permanente de imagens;
- API para o site público.
